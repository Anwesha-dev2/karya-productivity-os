# Kārya — Personal Productivity Operating System

> A personal space to organize tasks, build habits, manage focus sessions, and understand your productivity.

**Kārya** is a personal productivity application designed to bring everyday planning and productivity tracking into one organized workspace.

The goal is to create a simple yet powerful system that helps users manage their daily responsibilities, maintain consistency, and track their progress over time.

## ✨ Features

### Task Management
- Create, edit, and delete tasks.
- Set task priorities and deadlines.
- Organize tasks by categories and tags.
- Track task completion and progress.
- Manage subtasks and task status.

### Habit Tracking
- Create and organize personal habits.
- Track daily habit completion.
- Monitor consistency over time.
- View activity through a contribution heatmap.

### Pomodoro Focus Timer
- Customizable focus duration.
- Short and long breaks.
- Start, pause, resume, and reset sessions.
- Track completed focus sessions.

### Productivity Dashboard
- Daily productivity overview.
- Task completion statistics.
- Productivity streaks.
- GitHub-style activity heatmap.
- Visual productivity analytics.

### User Experience
- Dark-first interface.
- Responsive design.
- Interactive components and animations.
- Local data persistence using browser LocalStorage.

## 🚀 Getting Started

### Prerequisites
- A modern web browser.
- Visual Studio Code (recommended).
- VS Code Live Server extension (recommended).

### Installation

1. Clone the repository:

```bash
git clone https://github.com/YOUR-USERNAME/karya-productivity-os.git
```

2. Open the project folder:

```bash
cd karya-productivity-os
```

3. Open the folder in Visual Studio Code.

4. Run `index.html` using Live Server.

No backend configuration is required for the current frontend version.
